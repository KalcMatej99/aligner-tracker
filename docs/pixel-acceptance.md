Use the verified artifact, not an arbitrary later CI build. Record exact app version, source commit, APK SHA-256 and signing-certificate SHA-256. No release key or publication is authorized by this checklist.

If it differs, **stop the update and resolve artifact/signing compatibility; do not uninstall the owner's app or clear its data to fix the mismatch**. Preserve the working install. Never install an instrumentation/test APK as the phone app.

Begin with disposable synthetic records. If personal records already exist, export an encrypted complete backup to a trusted local location, retain the password privately, and verify it through a preview and a disposable restore before replacing anything. Normal use with the owner's real prescribed plan comes after the synthetic destructive cases; never simulate a treatment change in real records.

The history fixture must include known covered dates before today, adjacent transitions around midnight, fully tracked and partial/unknown days, historical targets, actual tray boundaries and sample notes/appointments/photos where needed. Its expected-results sheet must state exact dates/times/totals and proposed correction values. Fresh onboarding starts tracking now; backdating a treatment start does not create earlier coverage. If a fixture is unavailable or rejected, mark the relevant historical cases BLOCKED, not PASS. Do not change the personal phone clock to manufacture history.

## Short core journey

These are the first owner-operated checks; then continue through the full checklist below.

1. **PX-01 — Install/setup:** verify the artifact and existing-data safeguards above. Open the app, read privacy/setup text, try one invalid input, then create a synthetic prescribed plan on a non-first tray with explicit IN/OUT state and Europe/Rome zone. Explain that earlier hours are unknown. Verify all entered values and the visible current state.
2. **PX-02 — Daily tracking:** Take out, background/reopen, then Put in. Confirm one state transition for each action, elapsed time derived from the saved timestamp and matching Today/History totals. Repeat a rapid tap; there must be no duplicate or contradictory record.
3. **PX-03 — Forgotten tap:** correct a non-initial event between its visible neighbors. Try an invalid future/out-of-order timestamp, then a valid correction. Verify rejection leaves data unchanged and the valid correction recalculates the affected totals. Use PX-06 for historical/midnight cases.
4. **PX-04 — Reminder comprehension:** keep notification permission denied, save a break reminder, and explain the visible blocked status. Grant notifications during the session, enable the needed channel, schedule a short synthetic break, lock the phone, and record actual scheduled/received times. Use the action to put aligners in and verify the record. Late delivery is an observation, not an invented on-time PASS.
5. **PX-05 — Backup comprehension:** export encrypted synthetic records to the local file picker, change a synthetic note/state, try the wrong password, then correct-password preview and Cancel. Explain replacement before confirming a final restore. Compare state, notes, history and photos against the saved snapshot; wrong-password and cancellation must preserve changes. PX-14/PX-15 complete the backup coverage.
