# Original project setup brief

Archived from the existing README inspected before initialization, 2026-09-08.

An Android app for tracking clear-aligner wear time, inspired by TrayMinder's functionality, with its own design and implementation.

Original status: project folder and initial brief created; app implementation had not started.

Purpose: help the user meet their orthodontist-prescribed daily wear target (approximately21–22hours in the initial personal brief) without a paid subscription. The app must use each user's prescribed target.

Initial features: one-tap aligners-in/out; configurable daily wear goal and worn/removed totals; reinsert reminders; manual corrections for forgotten actions; daily history/calendar/averages; current tray/change schedule/reminders.

Later candidates: home widget and notification controls; appointments and daily notes; photos/comparison/time-lapse; export/backup/restore; Wear OS.

Proposed defaults: native Android; local offline records with no account; no ads/subscription for core tracking; persisted timestamps survive closure/restarts; explicit midnight/timezone/DST behavior; no automatic treatment or tray-change decisions.

Original references: [TrayMinder Play listing](https://play.google.com/store/apps/details?id=com.invisatime), [FAQ](https://trayminder.com/post/frequently-asked-questions). Current evidence supersedes assumptions in these references where sources conflict; see research.md.
