## Performance evidence and limits

Debug builds on accelerated x86_64 emulators. API36 phone: two cores/3 GiB RAM; one synthetic 50,000-event run measured transactional restore 675 ms, 30-day summaries 24 ms, JSON round-trip 1693 ms, CSV 18 ms and 1 MiB encrypt/decrypt with both 600,000-round PBKDF2 derivations 4443 ms. API26 phone: two cores/2 GiB; the corresponding focused run measured 2016 ms, 22 ms, 884 ms, 20 ms and 3897 ms. Baseline and upgraded API26 cold launches were 1204 ms and 907 ms. These are observed samples, not comparable device benchmarks or physical budgets.

A Reports scroll sample contained 212 frames, 18 janky (8.49%), p50=27 ms, p90=34 ms, p95=42 ms, p99=48 ms. The GPU was emulated. KDF/image/archive processing runs off the UI thread; archive limits are 32 MiB and HTML output 16 MiB. No matched 24-hour battery or physical wakeup result is claimed.

The initial software-emulated startup ANRs were discarded as acceptance. Accelerated emulators were used without wiping existing app data; API26 upgrade used a newly created disposable AVD. No personal devices, accounts or shared runner service were changed by these acceptance lanes.
